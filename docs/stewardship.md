# Stewardship Guide

Version 1.0

## Purpose

Seiryū-en Companion is intended to remain useful for many years.

This document explains how future staff should care for the project.

The goal is continuity rather than constant redesign.

---

# Every Change Should Respect Three Things

## 1. The Garden

The physical garden is the primary experience.

The companion exists to support the garden.

Never allow the technology to become more important than the landscape.

---

## 2. The Historical Record

Interpretation should remain grounded in documented evidence.

When new research becomes available:

- update the companion
- preserve previous editorial history
- cite sources whenever practical

---

## 3. Future Staff

Every improvement should make the project easier—not harder—to inherit.

Avoid unnecessary complexity.

Document important decisions.

Leave clear notes for the next person.

---

# Editorial Review

Before publishing new content ask:

Is it accurate?

Is it documented?

Does it improve understanding?

Is it written clearly?

Does it encourage people to return to the garden?

If the answer to any question is "no," revise before publishing.

---

# Technology Review

Before adding new software ask:

Does this reduce long-term maintenance?

Will this still work in ten years?

Can someone else understand it?

Does it lock JACCC into one company?

Can the content be exported?

If not, reconsider.

---

# Annual Review

At least once each year:

- verify links
- review accessibility
- review historical information
- update photographs if appropriate
- review seasonal observations
- review acknowledgements

The companion should remain a living publication.

---

# Success

The project succeeds when future staff can continue caring for it without needing to rebuild it from scratch.
