Seiryū-en Companion.

It is independent of the underlying code and data structures.

# Interpretive Framework

The garden is interpreted through the three primary regions established
in the original design:

Upper Waterfall — Issei

Middle Stream — Nisei

Lower Pools — Sansei

This structure should remain the primary organizational framework for
the visitor experience.

Future features should strengthen this framework rather than replace it.

Examples of supporting content include:

• Plant
• Historical photograph
• Manyōshū poem
• Construction history
• Gardener knowledge
• Accessibility information

Visitors should move naturally between these related items.

---

# Visitor Questions

Every screen should answer one question.

Where am I?

What is this?

Why is it here?

What should I notice?

Where should I go next?
